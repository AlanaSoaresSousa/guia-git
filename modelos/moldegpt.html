POR QUE GIT?

Código sem controle vira caos.

Arquivos duplicados, alterações perdidas, medo de mexer no código e pastas como projeto-final-v2-agora-vai. Git resolve exatamente esse problema.

O FLUXO

Seu código. Um histórico.
Uma equipe.

Git controla cada mudança na sua máquina. GitHub transforma esse histórico em colaboração. Veja o caminho completo de uma alteração.

DEVELOPMENT WORKFLOW repository connected
01 · ESCREVA

Seu código

Você cria e modifica arquivos normalmente no seu computador.

src/
├── app.js
├── index.html
└── style.css
git add
02 · PREPARE

Staging

Escolha exatamente quais mudanças entrarão no próximo snapshot.

✓ app.js ✓ style.css ✓ index.html
git commit
03 · VERSIONE

Git

Cada commit cria um ponto no histórico que você pode consultar, comparar ou restaurar.

feat: dashboard a81c2e9 · 2 min ago
fix: auth flow 4f8b2a1 · yesterday
initial commit 91c0d72 · 3 days ago
$ git push origin main
04 · COLABORE

GitHub

Seu repositório deixa de existir apenas na sua máquina e passa a ser um espaço compartilhado para colaboração, revisão e integração.

12 commits
03 branches
08 pull requests
BRANCHES

Trabalhe sem quebrar tudo.

Branches permitem criar linhas paralelas de desenvolvimento. Você pode experimentar uma funcionalidade, corrigir um bug ou testar uma ideia sem comprometer a versão principal.

main — produção
feature/auth — nova funcionalidade
feature/ui — redesign
repository / gitbase 3 branches
feature/auth main feature/ui
